# DALT’4 · 2026 PlayX4 포트폴리오 시안

홈페이지 카드와 프로젝트 상세 화면의 배치·문구를 확인하기 위한 독립된 정적 시안입니다.

- `index.html`을 브라우저에서 열면 됩니다. 별도 설치나 빌드가 필요하지 않습니다.
- 홈페이지 카드 → 상세 화면 → PlayX4 현장 검증 섹션으로 이동할 수 있습니다.
- 공식 로고는 사용자가 제공한 원본 PNG입니다.
- 타이틀 그래픽은 시안용이며 실제 게임 화면이 아닙니다.
- 원본 설문 응답, 플레이어 식별자, 비공개 스프레드시트 링크는 포함하지 않습니다.
- 기존 홈페이지와 DALT-4 사이트를 교체하거나 수정하지 않습니다.
- main에 병합하여 GitHub Pages로 배포되면 `/playx4-preview/`에서 접근할 수 있습니다.
